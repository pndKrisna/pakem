# Aturan Eksekusi Proyek Pakem
- **DILARANG KERAS** menjalankan perintah terminal `mvn`, `mvn.cmd`, `javac`, atau `exec:java`. Subshell terminal Windows selalu menghasilkan karakter corrupt dan timeout saat menjalankan Maven.
- Tugasmu hanya membaca, membuat, dan mengedit kode Java serta memperbarui `PROGRESS.md`.
- Biarkan user yang melakukan `compile` dan menjalankan aplikasi secara manual lewat PowerShell.
